Aster for macOS

Open Aster for the first time

Follow these steps in order. You will copy the command first, then add the Aster app path straight from Finder.

  1. Move Aster to your Desktop

    Keep the Aster disk image window open. Drag the Aster app icon out of that window and drop it on your Desktop. Wait for copying to finish.

  2. Open Terminal

    Press Command (⌘) + Space, type Terminal, then press Return.

  3. Copy and run this command

    Click Copy command below. It includes a space at the end, so the app path can go right after it.

    xattr -dr com.apple.quarantine
    1. Click the Terminal window and press Command (⌘) + V. Do not press Return yet.
    2. Drag the Aster app from your Desktop into the Terminal window. Terminal will add the correct path for you.
    3. Now press Return. Wait until Terminal shows a new prompt.

    If dragging is awkward: click Aster on your Desktop, press Option (⌥) + Command (⌘) + C to copy its path, then paste that after the command in Terminal.

  4. Open Aster

    Go back to your Desktop and double-click Aster.

    If Terminal says “Operation not permitted,” open System Settings → Privacy & Security → Files & Folders → Terminal, turn on Desktop Folder, quit and reopen Terminal, then repeat step 3.

This command removes macOS's download quarantine from the Aster app path you add after the command. Run it only if you trust your Aster download. It does not sign or notarize the app.
